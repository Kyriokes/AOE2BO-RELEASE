# AoE2 BO Coach: downloads

Windows releases of **AoE2 BO Coach**, an overlay for Age of Empires II: Definitive Edition that follows your build order by reading the screen only.

- **Latest version:** [BoCoach-win-x64.zip](https://github.com/Kyriokes/AOE2BO-RELEASE/releases/latest/download/BoCoach-win-x64.zip). Unzip it anywhere and open `BoCoach.exe`; nothing to install.
- **All versions:** [Releases](https://github.com/Kyriokes/AOE2BO-RELEASE/releases). Each one comes with its `.sha256` to check the file.
- **The website, with the build order library and editor:** https://aoe2-bo-coach.vercel.app
- **Something went wrong?** Open an [issue](https://github.com/Kyriokes/AOE2BO-RELEASE/issues).
